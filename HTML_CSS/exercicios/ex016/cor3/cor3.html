Site de Exemplo

Primeiro titulo:HTML

HTML (HyperText Markup Language) é a linguagem padrão de marcação para estruturar páginas web, definindo elementos como parágrafos, cabeçalhos, imagens e links, interpretados pelos navegadores

Segundo Titulo:CSS

CSS (Cascading Style Sheets) é a linguagem padrão para estilizar documentos HTML/XML, controlando o layout, cores, fontes e responsividade. Ela separa o conteúdo da apresentação, permitindo criar sites atraentes e organizados. Funciona com base em regras (seletor e declaração) e funciona em cascata.

Terceiro titulo: Javascript

JavaScript é uma linguagem de programação de alto nível, interpretada e dinâmica, essencial para o desenvolvimento web front-end, permitindo criar interatividade, animações e manipulação de conteúdo (DOM) diretamente no navegador.
